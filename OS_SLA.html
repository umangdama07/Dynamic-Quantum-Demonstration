Welcome to the Project

CPU scheduling is an important function of an operating system. It decides which process gets the CPU and for how long.

This project demonstrates FCFS, standard Round Robin, and an educational dynamic-time-quantum scheduling approach inspired by the research paper studied in Stage 1.

Research Paper Overview

Enhanced Round Robin with Dynamic Time Quantum

Standard Round Robin gives each ready process a fixed time quantum. A very small quantum can cause frequent context switches, while a large quantum can reduce responsiveness.

Dynamic-time-quantum scheduling aims to adjust the quantum according to process-related information to balance CPU efficiency and fairness.

Project Objectives

  • Understand CPU scheduling algorithms.
  • Simulate process execution and display a Gantt chart.
  • Calculate completion, turnaround, and waiting times.
  • Compare scheduling results using the same input data.
This simulator implements the main ERRDTQ rules described in the paper: the ready queue is sorted by remaining burst time, the time quantum is recalculated using the paper's rounded 80th-percentile position, and the scheduler checks the one-third-quantum preemption condition when new processes arrive. The paper's percentile indexing is interpreted as one-based, matching its worked example.

Real-life scenario: Cloud server task scheduling

Algorithm Comparison

FCFS: Executes processes in arrival order without preemption.

Round Robin: Gives each ready process a fixed time quantum and returns unfinished processes to the queue.

Dynamic Quantum Demonstration (ERRDTQ): Sorts active processes by remaining burst time, recalculates the 80th-percentile quantum at arrival/completion checkpoints, and applies the paper's one-third-quantum preemption rule.

Run each algorithm using the same process inputs and compare the waiting time, turnaround time, CPU utilization, and throughput.
